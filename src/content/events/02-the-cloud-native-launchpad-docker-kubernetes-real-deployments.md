## About This Event

This interactive virtual workshop introduced students and aspiring technology professionals to cloud native computing, containers, and Kubernetes. Participants explored how modern applications are deployed and managed.

## What You'll Learn

- Cloud native computing and the CNCF ecosystem
- Why organizations use containers and Kubernetes
- Docker fundamentals and containerization
- Kubernetes architecture, Pods, Deployments, Services, and declarative configuration
- Scaling, self-healing, and basic deployment troubleshooting
- Cloud native learning paths and CNCF certifications

## Live Hands-On Demonstration

The session included a sample application deployment to Kubernetes, covering:

- Writing Kubernetes YAML manifests
- Exposing the application through Services
- Scaling workloads across multiple replicas
- Observing self-healing behavior
- Troubleshooting common deployment errors

## Who Should Attend

- Computer Science, Software Engineering, IT, and AI students
- Beginners interested in cloud computing and DevOps
- Aspiring Cloud, Platform, and DevOps engineers
- Open-source enthusiasts and CNCF community members
