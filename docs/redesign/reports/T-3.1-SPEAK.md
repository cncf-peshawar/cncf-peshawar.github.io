## 6. Deviations ($\le 3$)

1. **Mobile Button Word Wrapping:** Below 640px viewport width, the primary CTA button text (`"Submit Talk Proposal on GitHub (CFP)"`) switches from `white-space: nowrap` to `white-space: normal; padding: 10px 14px; text-align: center;`. This prevents the 382px unpadded button text from exceeding the 358px mobile content box at 390px, ensuring strictly 0 horizontal overflow.
2. **Interactive Mentor Speech Bubble Hover:** Added a subtle brutalist `translate(2px, -2px)` hover effect with `--shadow-hard-sm` on the speaker support robot doodle bubble to enhance delight while strictly respecting `@media (prefers-reduced-motion: reduce)`.
3. **Empty Speaker Collection Fallback Notice:** In the absence of speakers in the local markdown collection during early development waves, the speakers section renders a clean brutalist dashed empty state prompt inviting the first community member to apply, instead of rendering a broken or empty grid.
